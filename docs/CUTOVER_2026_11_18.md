## Защита от случайного legacy sync

**`sync.js`** (полный DrJaw → Supabase) **по умолчанию завершается с exit code 2** и не выполняет ETL.

Разрешён только явный override:

- `node sync.js --force-cutover-override`, или
- `ALLOW_LEGACY_MSSQL_FULL_SYNC=true` в окружении.

`sync-daemon.js` вызывает тот же `sync.js` — без override daemon **не** выполнит полный импорт (даже при `sync_requested = true`). Для cutover держать **`sync_requested = false`**.

Рекомендуемые операции вместо full sync:

| Задача | Скрипт |
|--------|--------|
| Предпусковой / контрольный срез | `node scripts/full-cutover-audit.js` |
| Сверка партии 37 | `node scripts/check-37-batch.js` |
| Точечный импорт по `Items.Id` | `node scripts/import-items-id-range.js <min> <max>` |
| Проданные на MSSQL, но `active` в SB | `node scripts/archive-mssql-sales.js` (с `--apply`) |
